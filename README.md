# Rick-and-Morty-App
Rick &amp;
A Flutter Rick and Morty app built using REST APIs, Dio, and Cubit/BLoC for state management.

In this project, I practiced:

* Using the Offline Builder package to handle offline and online states.
* Adding animated illustrations from unDraw.
* Using the Animated Text package for engaging UI effects.
* Implementing Hero animations for smooth screen transitions.
* Working with CustomScrollView for advanced scrolling layouts.
* Structuring the project into Presentation, Data, and Logic layers for better code organization and maintainability.
* Building a responsive and user-friendly UI.
* Implemented search and filtering functionality to easily find characters based on their names.
